# 💊 AI Pharmacy — RAG Chat Assistant

A Retrieval-Augmented Generation (RAG) app: upload a pharmacy/medical PDF
(drug leaflet, formulary, clinical guideline, etc.), and ask questions about
it. Answers are generated by a **free Groq-hosted LLM**, grounded strictly in
the content you uploaded.

> ⚠️ **Disclaimer:** This is an educational/demo project. It is **not**
> a substitute for advice from a licensed pharmacist or doctor, and should
> not be used to make real medication decisions.

## How it works

```
PDF upload
   │
   ▼
Extract text (pypdf)
   │
   ▼
Chunk text (LangChain RecursiveCharacterTextSplitter)
   │
   ▼
Embed chunks (local, free: sentence-transformers/all-MiniLM-L6-v2)
   │
   ▼
Store vectors (FAISS, in-memory)
   │
   ▼
User question ──► retrieve top-k relevant chunks ──► Groq LLM ──► grounded answer
```

- **Chunking & tokens:** handled by LangChain's text splitter (character-based
  chunking with overlap, so context isn't cut mid-sentence).
- **Embeddings:** generated **locally and for free** with a HuggingFace
  sentence-transformer model — no embedding API key needed.
- **Vector store:** FAISS, kept in memory per session (resets when you
  upload a new file or restart the app).
- **LLM:** [Groq](https://console.groq.com) — free tier, no credit card,
  extremely fast inference. Model is selectable in the sidebar.

## 1. Get a free Groq API key

1. Go to <https://console.groq.com/keys>
2. Sign up (no credit card required for the free tier).
3. Create an API key (starts with `gsk_...`).

## 2. Run locally

```bash
git clone <your-repo-url>
cd ai-pharmacy-rag

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt

cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# then edit .streamlit/secrets.toml and paste your real GROQ_API_KEY

streamlit run app.py
```

The app opens at `http://localhost:8501`. If you don't set up
`secrets.toml`, you can also just paste the API key directly into the
sidebar text field at runtime.

## 3. Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: AI Pharmacy RAG app"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

Make sure `.streamlit/secrets.toml` is **not** committed (it's in
`.gitignore` already) — only `secrets.toml.example` should be in the repo.

## 4. Deploy on Streamlit Community Cloud

1. Go to <https://share.streamlit.io> and sign in with GitHub.
2. Click **"New app"**, pick your repo, branch (`main`), and set the main
   file path to `app.py`.
3. Before/after deploying, open **App settings → Secrets** and add:
   ```toml
   GROQ_API_KEY = "gsk_your_real_key_here"
   ```
4. Click **Deploy**. First build takes a few minutes (it downloads the
   embedding model). Subsequent restarts are much faster.

Your app will be live at `https://<your-app-name>.streamlit.app`.

## Notes & tips

- **Free tier limits:** Groq's free tier is rate-limited (requests/day and
  tokens/minute, varies by model). If you hit a rate limit, wait a bit or
  switch models in the sidebar. Check current limits at
  <https://console.groq.com/docs/rate-limits>.
- **Model availability changes:** Groq's model catalog is updated
  periodically. If a model in the dropdown errors out, check
  <https://console.groq.com/docs/models> for the current list and update
  `GROQ_MODELS` in `app.py`.
- **Scanned PDFs:** this app extracts text directly from the PDF. Scanned
  image-only PDFs won't work unless you add OCR (e.g. `pytesseract`) as an
  extra step.
- **Resource limits on Streamlit Community Cloud:** the free tier has ~1GB
  RAM. The embedding model (`all-MiniLM-L6-v2`, ~80MB) is chosen
  specifically to stay lightweight; very large PDFs (hundreds of pages) may
  still be slow to embed.
- **Data persistence:** the FAISS index lives in memory for the session
  only. Uploading a new PDF or restarting the app clears it — there's no
  database in this version.
